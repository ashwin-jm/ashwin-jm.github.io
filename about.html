About

Hi, I'm Ashwin.

I'm a data engineer with 3 years of experience in data engineering, data warehousing and data modelling. I turn messy data from many sources into analytics-ready datasets.

I started out scraping and cleaning data at Datahut, building 10+ automated scrapers and writing 10+ technical articles. At QBurst Technologies I built AWS pipelines (S3, Lambda, RDS, Glue, Athena, Terraform) and a FastAPI tool that uses Claude and GPT models to plan data migrations.

Today I'm a data engineer at Wizr AI, building ingestion from Azure into Microsoft Fabric OneLake with scheduled and event-based triggers.

I have a strong interest in machine learning, and I'm focused on building scalable cloud data systems and continuously improving data workflows.
